31. WALIDACJA „ZŁE POLE W ZŁYM BLOKU”
------------------------------------
Status: GOTOWE

Co działa:
- ostrzeżenie, gdy użytkownik wpisze pole niepasujące do trigger sub-blocku
- przykładowo:
  - `relation = { ... }` -> dozwolone tylko `country`, `value`
  - `alliance/vassal/war/dynastic/truce/union = { ... }` -> tylko `country`
  - `core_national/core_claim/core_casusbelli/owned/control = { ... }` -> tylko `province`, `data`
  - `ownerchange/controlchange = { ... }` -> `province`, `years`, `months`, `days`
  - `fortresslevel/provincepopulation = { ... }` -> `province`, `data`
